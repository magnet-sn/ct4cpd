# ct4cpd - PowerToys Command Palette 向け Core Temp 温度表示プラグイン (改修版)

Core Temp の共有メモリ（Memory-Mapped File）から CPU 各コアの温度を取得し、PowerToys **Command Palette** のドック（Dock Bands）およびコマンドリストに表示する拡張機能です。

---

## 🌟 改修内容（新機能・視認性と統一感の改善）

### 1. 「下段の灰色・見づらさ」の解消（Title単行レイアウト）
Command Palette の UI 仕様上、下段（Subtitle）はフォントが小さくセカンダリカラー（薄い灰色）で描画されるため視認性が悪くなっていました。
改修版では **Subtitle（下段）への温度割り当てを全廃** し、すべての温度を **Title（上段・鮮明なメイン文字色）のみ** で表示するように統一しました。
どのコアの温度も同じフォントサイズ・同じ鮮明さでくっきりと視認できます。

---

### 2. 「4の倍数でないときの統一感の崩れ」の解消
6コア、10コア、12コア、14コアなどのCPUで、4コア固定や上下2段構造にすると最後のブロックだけ空欄や欠けが生じ、全体の高さや幅のバランスが崩れていました。
これを解消するため、**1枠あたりのコア数を柔軟に選択可能** にし、デフォルトを最も崩れにくい **「2コア / 枠」** に設定しました。

| 表示モード | 概要 | 統一感と特徴 |
| :--- | :--- | :--- |
| **縦ドック推奨: 2コア / 枠 (`Per2Cores`)** | 1枠に2コアを表示（デフォルト） | **4, 6, 8, 10, 12, 14, 16, 20, 24コアなど全ての偶数コアCPUで完全に均等分割** され、端数が出ず完璧に統一されます。 |
| **縦ドック細幅: 1コア / 枠 (`Per1Core`)** | 1枠に1コアのみを表示 | 極細の縦置きドックに最適。コア数に関係なく100%均一なブロックが並びます。 |
| **横ドック向け: 4コア / 枠 (`Per4Cores`)** | 1枠に4コアを横並びで表示 | 画面上下の横置きドック向け。4の倍数でない場合でも単行で文字間隔が揃います。 |
| **サマリー表示 (`Summary`)** | 最高温度と平均温度を1枠に表示 | `MAX 52°  AVG 46°` をTitleのみでコンパクトに表示します。 |

#### 設定可能な項目（Command Palette の [拡張機能の設定] から即時変更可能）
1. **ドック表示レイアウト**: 上記4モードから選択。
2. **コア番号表示**: ONにすると枠の先頭に `0-1: 45 48` や `#0: 45°` のようにコア番号を付加。
3. **単位表示**: `°C` を付加するかどうか。
4. **数字間の間隔**: 「全角スペース (広め)」「半角スペース2つ (標準)」「半角スペース1つ (狭め)」から選択。
5. **更新間隔**: 1秒 / 2秒 (標準) / 3秒 / 5秒。

---

### 3. 不具合の改善
* **残像バグの完全解消**: Core Temp を終了した際や未起動時、2ブロック目以降の古い温度表示を即座に空文字クリア。
* **動的コア数適応**: プラグイン起動後に Core Temp が立ち上がっても、実際のコア数（24コアなど）に合わせて自動でドック枠を拡張・追従。
* **多重実行防止と安全なリソース破棄**: タイマー更新時の多重実行防止（`Interlocked`）および安全な破棄。
* **詳細画面の実装**: Command Palette で `ct4cpd`（または「CPU 温度詳細」）を選択すると、全コアの温度一覧、最高/平均/最低温度、およびCore Temp接続状況をGUIで確認可能。
